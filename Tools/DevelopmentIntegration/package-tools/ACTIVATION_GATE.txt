Runtime and frontend manifests are generated from the actual packaged bytes.
Working-checkout builds remain SourceDirty=true and fail the existing runtime gate.
Only an exact Git archive verified against an explicit repository/commit/tree can
produce SourceDirty=false. Overlaid files and unarchived inputs are rejected.
An uncommitted packager cannot be overlaid into an old archive and called clean.
Clean metadata establishes provenance, not deployment approval or real binding qualification.
Service/account/key/reference setup and cutover remain separate approvals.
No production service configuration, secret, signing key or ticket is packaged.
