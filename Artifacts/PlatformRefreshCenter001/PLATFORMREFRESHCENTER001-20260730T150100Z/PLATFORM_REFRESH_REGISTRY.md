# Platform Refresh Registry

The authoritative static registry is `Tools/PlatformRefreshCenter/PlatformRefreshRegistry.json`. It contains exactly twelve unique dataset IDs, fixed metadata providers, truthful capability flags, dependencies, source identifiers, concurrency group, operator warnings, and follow-on milestones.

The deployed control host validates the contract version, exact dataset count, uniqueness, required fields, and the single qualified routine-refresh owner at startup. Normal browser input cannot add a dataset, source path, database, script, or command.
